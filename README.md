# ML-NMR-B: ISPOR Europe 2026, Vienna

Beamer slides for the podium talk *Bridging disconnected networks and single-arm studies with multilevel network meta-regression (ML-NMR-B)*.

- `main.tex`: the deck (16:9, compile with pdfLaTeX). Diagrams are TikZ, the results plot is TikZ drawn from Appendix Table A3 of the paper.
- `figures/`: network plots from the paper (node colours matched, legends removed).
- Speaker notes are `\note{}`s. To view them, uncomment the `\setbeameroption` line near the top of `main.tex`.
